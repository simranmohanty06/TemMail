# TemMail Website

This is a simple temporary email website that allows users to generate disposable email addresses for temporary use. It provides users with a convenient way to receive emails without revealing their personal email addresses.

## Features

- Generate random disposable email addresses
- Receive emails sent to the generated addresses
- View email content and attachments
- Delete emails when no longer needed

## Technologies Used

- HTML
- Bootstrap CSS
- JavaScript
- 1secmail API

## Usage

1. Visit the website and generate a disposable email address.
2. Use the generated email address to receive emails.
3. Refresh the page to check for new emails automatically.
4. Click on an email to view its content and attachments.
5. Delete emails when no longer needed.
